# 时间复杂度及空间复杂度介绍
大家好鸭！今天我们来学习时间复杂度和空间复杂度。  

在计算机科学中，时间复杂度和空间复杂度是衡量算法效率的重要指标。它们帮助我们了解算法在处理不同规模输入时，所需的时间和空间资源。

## 1. 什么是时间复杂度和空间复杂度？

时间复杂度（Time Complexity）**
  表示算法执行所需的时间随输入规模变化的增长趋势。它告诉我们算法运行速度的快慢。  

空间复杂度（Space Complexity）**
  表示算法执行过程中所需的额外内存空间随输入规模变化的增长趋势。它告诉我们算法占用内存的多少。

*注意：  
  值得提的是，算法的运行用时并非完全由输入规模决定，而是也与输入的内容相关。所以时间复杂度一般又分为：  
  1.最坏时间复杂度   
  2.平均时间复杂度  
  3.最好时间复杂度*  

- 一般情况下时间复杂度默认为**最坏时间复杂度**。
  

## 2. 为什么需要复杂度？

评估效率 **
  通过复杂度，我们可以预测算法在处理大数据时的表现，避免选择效率低下的算法。

优化资源 **
  了解时间和空间的消耗，有助于在有限资源下设计更合理的程序。

比较算法 **
  不同算法解决同一问题时，复杂度是选择最优算法的重要依据。

## 3. 怎么表示时间&空间复杂度？
### **大O表示法（big O notation）
Q：同一段代码，在你的电脑上跑要0.01秒，在超级计算机上跑却只要0.0001秒，我们能说在超算上的时间复杂度比在你的电脑上的时间复杂度低吗？  

A：答案当然是否定的，同一段代码理应拥有相同的复杂度。

在现实生活中，我们经常会遇到这样的情况。所谓「用时随数据规模而增长的趋势」是一个模糊的概念，为了具象化规范化复杂度，我们引入了使用广泛的“**大O表示法**”统一描述算法的时间复杂度和空间复杂度。

形如：$O(n)$；$O(n²)$；$O(logn)$；$O(1)$ ...  
*其中 “n" 表示数据规模*

(含义讲解和计算方式将留在下一板块讲解)


## 4. 计算认识时间复杂度和空间复杂度
### ***核心思想：抓大放小***
- 抓住影响复杂度的**决定因素**，其余皆可忽略不计  
（例如函数$y = n^2 + n + 1$，其决定因素就是$n^2$，计算时间复杂度只需考虑 $n^2$ 即可）
---

### 1.时间复杂度计算

#### ① $O(1)$ —— 常数阶（最快）
* **含义**：无论数据量 $n$ 有多大，执行时间都是恒定的，不随 $n$ 的改变而改变。
* **通俗比喻**：不管一本字典有 100 页还是 10,000 页，翻到第 1 页只需要 1 秒。
* **代码示例** (Python)：
  ```python
  def get_first_element(arr):
      return arr[0]  
      # 无论数组有多长，只取第一项，一步到位

#### ② $O(\log n)$ —— 对数阶（极快）
* **含义**：每循环一次，待处理的数据量减半。随着 $n$ 增大，时间增加得非常缓慢。
* **通俗比喻**：**二分查找**。在厚厚的字典里找一个词，先翻到中间，如果目标在前半本，就把后半本撕掉；再对前半本取中间……每次排除一半的页面。
* **代码示例**（Python）：
  ```python
  # 二分查找
  def binary_search(arr, target):
      low, high = 0, len(arr) - 1
      while low <= high:
          mid = (low + high) // 2
          if arr[mid] == target:
              return mid
          elif arr[mid] < target:
              low = mid + 1
          else:
              high = mid - 1
      return -1

#### ③ $O(n \log n)$ —— 线性对数阶（较快）
* **含义**：把线性阶和对数阶结合起来。许多高效的排序算法（如归并排序、快速排序）都是这个级别。
* **通俗比喻**：把大堆数据分成两半，分别排序，再合并。  
* **代码示例** (Python)：
  ```python
  # 归并排序核心思想（分治法）
  def merge_sort(arr):
      if len(arr) <= 1:
         return arr
      mid = len(arr) // 2
      left = merge_sort(arr[:mid])
      right = merge_sort(arr[mid:])
      return left + right  # 简化示意合并过程


#### ④ $O(n)$ —— 线性阶（中规中矩）
* **含义**：运行时间与数据量 $n$ 成正比。数据翻倍，时间也翻倍。
* **通俗比喻**：顺序查找。一页一页地从头翻到尾，直到找到那个单词。
* **代码示例** (Python)：
  ```python
  # 顺序查找
  def sequential_search(arr, target):
      for i in range(len(arr)):
          if arr[i] == target:
              return i
      return -1

#### ⑤ $O(n^2)$ —— 平方阶（比较慢）
* **含义**：通常出现在双层嵌套循环中。数据量翻倍，时间变成原来的 4 倍。
* **通俗比喻**：双重遍历。要检查全班每个同学和另外所有同学的握手情况。
* **代码示例** (Python)：
  ```python
  # 打印乘法口诀表或双重循环
  for i in range(n):
      for j in range(n):
          print(i, j)

#### ⑥ $O(2^n)$ —— 指数阶（灾难般的慢）
* **含义**：随着 $n$ 的增加，运行时间呈爆炸式增长，通常在算法设计中要极力避免。
* **通俗比喻**：递归计算斐波那契数列
* **代码示例** (Python)：
  ```python
  # 递归计算斐波那契数列（指数级重复计算）
    def fibonacci(n):
        if n <= 1:
           return n
        return fibonacci(n - 1) + fibonacci(n - 2)

### 2.空间复杂度计算

#### ① $O(1)$ —— 常数阶
* **含义**：算法额外申请的内存空间大小是个固定值，不随输入数据 $n$ 的变化而变化。
* **代码示例** (Python)：
  ```python
  def sum_two(a, b):
    c = a + b  
    return c
    # 只用了固定的变量 a, b, c，无论输入多大，额外内存不变

#### ② $O(n)$ —— 线性阶
* **含义**：额外开辟的存储空间与输入数据量 $n$ 成正比。
* **代码示例** (Python)：
  ```python
  def create_list(n):
    new_list = []
    for i in range(n):
        new_list.append(i)  # 列表随着 n 的增大，线性增长
    return new_list

#### ③ $O(n^2)$ —— 平方阶
* **含义**：通常需要创建一个二维矩阵或网格来存储数据，内存消耗随 $n$ 的平方增长（例如 $n \times n$ 的棋盘或邻接矩阵）。
* **代码示例** (Python)：
  ```python
  def create_matrix(n):
    matrix = []
    for i in range(n):
        row = [0] * n  # 每一行有 n 个元素
        matrix.append(row)
    return matrix  # 整体存储空间随 n 的平方增长


## 5. 总结

| 复杂度类型 | 含义               | 计算关注点           | 例子               |
|------------|--------------------|----------------------|--------------------|
| 时间复杂度 | 算法运行时间增长趋势 | 基本操作执行次数     | 循环次数           |
| 空间复杂度 | 算法占用内存增长趋势 | 额外分配的内存空间   | 数组大小           |
---
- 计算复杂度时牢记“**抓大放小**”  
计算时间复杂度时，找出基本操作（例如循环中的比较、赋值等）  
计算空间复杂度时，计算变量占用空间（包括输入数据、辅助变量、递归栈等）

- 理解时间和空间复杂度，有助于写出高效且节省资源的程序。  
- 再次提醒：
大O符号表示的是算法的增长趋势，不是具体的执行时间或内存大小。

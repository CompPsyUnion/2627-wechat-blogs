# Agent 的入门使用教程

## 前言

离开熟悉而稳定的高中，进入充满多元性的大学，你是否也有这样的经历与感受：同学打开电脑就是一个 Agent 在跑任务，朋友的聊天中充满了陌生的词汇，小组作业时同学在短时间内非常高质量的完成任务；你是否感到焦虑与迷惑，是否想要将 Agent 为自己所用却不知道如何开始。**本篇文章将系统地带你了解 Agent 的相关知识与使用示例，帮助你快速入门**。同样的，本篇文章不会涉及过多各领域的垂直专精操作，搭建 Agent 和企业级 Agent 开发等内容。（不浪费大佬时间，这是一篇非常基础的文章）

## 第一部分：基础知识——介绍 Chat 与 Agent 的区别，AI 的相关名词，和大多数 Agent 的使用指南

### Chat 和 Agent

（我在这里就不贴官方定义了，字太多了，大家想看可以 AI 一下）

1. Chat 相当于更加智能的搜索框
2. Agent 相当于一个员工，一般情况下，在 Agent 里你可以获得同一家公司里**更高级的模型的更高思考强度**。此外，Agent 可以更加自主的完成任务，比如：利用命令行操控你的电脑，使用你电脑里的工具等，这些会在后面详细展开。**总而言之，你把 Agent 当成一个十分勤劳且在某些领域非常厉害的人就好了**

### 常见 AI 名词介绍（6、7、8 最重要）

1. API：相当与一个水龙头，你在某个 Agent 或者网站里通过“API Key”接入某个大模型，使用这家公司提供的算力，这些算力就像水一样流进了页面。当然，你需要提前充值算力，你的钱也会像水一样流走。这里科普一个常识：通过 API 使用 AI 一般情况下性价比要低于通过官方 Agent 购买 Plan，所以除 DSH 外基本不用 API（新手期）
2. MCP：这个可以理解为大模型和其他软件或网站的一种协议，通过 MCP，大模型可以快速操作软件或网站。（日常使用用不到，本人还没接触过）
3. Skill：与其叫技能，鄙人认为叫**标准化操作规则**要好理解的多。就是给大模型一套操作输入的规则，让大模型按照规则来处理。比如：你扔进去一篇论文，装一个 Skill，完事后论文就变成香香软软的核心产出与关键数据汇总啦
4. 提示词：字面意思，提示大模型怎么做，引导它。但是据说现在很多提示词会限制大模型性能，不好说，一般我会丢进去一些限制性较弱的提示词。（其实就是指向性比较模糊，因为我也不清楚到底想要什么，大模型会沿着我的思考找到我到底要什么）
5. 专家：这个已经是过时的概念了，可以 AI 考古一下，就不细说了
6. Harness：大模型的控制层，不负责思考，只负责管理工具调用，处理异常，组织任务循环。Harness 可以在很大程度上决定大模型的性能能得到多大的释放，这也是为什么 DSH 的 v4.1 和其他的 v4.1 不是同一种体验的原因
7. LLM：大模型
8. 对了，还有一个很重要的事情，Agent = Harness + LLM
9. 连接器：让 Agent 和其他软件连接（微信，QQ），可以通过 MCP 协议实现
10. 插件：Agent 分为内核层，插件层，控制层。

    - Kernel（内核层）：最小的 Agent 循环，只暴露扩展点，完全不知道任何插件的存在，只跟 Hook 接口对话。
    - Plugin（插件层）：实现具体的 Hook，挂载到单个会话上，用来改变 Agent 的行为。
    - Controller（控制层）：负责编排多个会话，可以组合插件，但插件反过来并不知道控制器的存在。

- 越狱：诱导模型绕过安全限制。
- 过拟合：模型过多的受训练数据影响，泛化性下降

之后好像在入门阶段也没有什么特别重要的词汇了，大家遇到感兴趣的词汇可以自由搜索一下

## 第二部分：分别介绍当下可用的各大主流 AI 模型和常见 AI 应用或工具；各模型适配人群；对于不同类型任务思考强度及模型推荐，Skill 推荐，插件推荐，提示词推荐

### WorkBuddy

WorkBuddy 是一款非常好上手，非常好获取，在国内生态很强的软件。**但是**，这个 Agent 不好用，输出的效果太蠢

### DSH（DeepSeek Harness）

DSH 是国内能用到几乎是最好的 Agent，缺点是没有免费积分赠送，需要纯自己充值 API，但是整体来说能在花费很少的情况下获得较好的产出。并且你要自己安装合适的插件，没有插件的 DSH 很拉。优点是运行速度非常快，产出虽然比不上 Codex，Claude Code 那么好，但也是国产 Agent 里几乎最好的，性价比在全球也是几乎最好的了。

### Codex

Codex 除了贵以及难以获取外，坏处比较少（当然，是在不和 Claude 比较的前提下）缺点：国内连接速度比较慢，运行速度没有 DSH 快，性价比没有 DSH 高，基本上没有其他缺点（虽然性价比不顶级，但是真正干重要的活儿的时候，谁会放心交给其他没有那么优秀的模型呢？贵一点就贵一点吧，用起来不烧心）

### CC Switch

CC Switch 这个准确来说不是一个 Agent，是一个多 Agent 协作平台，通过连接其他 Agent API，统筹多 Agent 合作。但是你也知道，API 是比较贵的，所以多 Agent 协作与性价比之间要取舍一下。并且，多 Agent 协作在入门期用处不大，这里就不展开了，以后熟悉了可以多多尝试。

### PI

1. PI 是一个极简的开源 Harness，字面意思，它是没有自己的模型的，你需要购买 API Key 来使用。默认只有读，写，改文件和 Bash 几个工具，也就是说你点开以后是一个终端，没有图形化界面，没有其他你熟悉的 Agent 内置功能（插件，连接器，自带的专家等乱七八糟的东西）。好处是轻量化（软件占用空间轻量化与省 Token），高度定制化（你甚至可以使用 Claude Code），和非常极致的成本控制。你需要自己添加许多插件来让她好用。
2. 不过大家不用在这个阶段过多关注，现在还用不到，等你熟悉 Agent 基础操作后就很容易学习了

## 第三部分：介绍 AI Agent 的各类常见适用场景

### 网站信息浏览

可以将网址复制后发给 Agent，让 Agent 帮你梳理网站信息。**需要输入账户和密码登录的网站，目前没有 100% 安全的使用 Agent 辅助梳理网站信息的方法，即便在安全箱内用 Agent 也有泄露个人信息的风险，有这样被他人搞到个人账号信息的案例，网络空间有很多脑残，喜欢干这种恶心人的事情**（教大家如何判断哪些 Agent 辅助浏览网站的行为是高风险的：把网址复制给 Agent，报错说需要输入密码无法访问网站的情况，就是不能用 Agent 辅助浏览网站的情景）

### 电脑各类神奇故障排查

有没有遇到电脑网络不通畅的情况，有没有遇到文件找不到的情况，有没有遇到电脑莫名奇妙出故障的情况。基于 Agent 可以在你的授权下，读取并操作电脑的特性，Agent 可以充当你的电脑医生帮助你排查问题。这可以极大的提升电脑这种复杂物品的使用体验感，让你的生活变得很舒服。总之，有什么问题（各种各样的问题），拍给 AI 吧！

### 文件查找与梳理

在我的使用体验中，Agent 很多时候可以充当一个电脑操作页面，可以通过与 Agent 对话，把操作电脑变成一件比使用手机还简单的事情。比如查找文件，文件繁多的文件管理器，很多时候真的没有点开的欲望，如果再加上你一开始没有养成一个文件分类的习惯，那电脑使用起来体验感不亚于坐牢。这时候，让 Agent 帮你找文件，告诉它可能的文件名，让它告诉你文件地址，再在资源管理器的搜索栏中搜索，简直不要太惬意。虽然还是建议大家认真管理电脑，但可以用 Agent 过度一下或者辅助整理不是吗？**使用 Agent，正在让“your attention is everything”越来越传神。**

### PDF 和 Word 辅助排版

还在一个字一个字的书写 PDF 和 Word 吗？青协布置下来策划案，HU 面试要制作策划，别的同学和小组还在纯手搓。而你，我的朋友，直接用 Agent 对同龄人降维打击。将制作指导，边界约束，和所在组织可能有点往期推文发给 Agent，就可以在多时间内获得一篇草稿了。你知道为什么 AI 写的文章初看问题不大，细看如同垃圾依托吗？

1. 废话太多，非常多句子，前一句给出观点，后一句专门否定反向观点，简直不要太啰嗦。
2. 有很多防御性写作，用词很空洞，读起来很费劲。
3. AI 用的语序非常不符合人类习惯，比如 AI 喜欢先描述情景再说重点。
4. 有些 AI 非常喜欢用很多“破折号”和“冒号”。
5. AI 写的很多文章缺少细节，读起来有一种读不到关键的感觉，联系上下文找一些细节加进去

### 论文重点梳理

读论文太费劲？用 Agent 去掉里面的废话，提炼出有效内容或者你需要的内容，加一些美味 Skill 会很舒服。注意使用边界，先去读一下 UNNC 的 AI 使用政策，或是问一下学长或老师

### 课程内容梳理

上课没跟上？自学不知从何开始？不如找一个智商够高的 Agent，把课件丢给她，让她来但你的一对一老师。**冷知识：顶级模型的综合能力不会比一些水教授差。（当然，很多时候多找有本事的老师请教还是很有用的，毕竟有些经验与线下个性化答疑还是 AI 望尘莫及的）**

### 论文论据来源辅助搜集

不建议使用 Codex 等 Agent 直接装 Skill 搜索汇总相关论文，许多论文网站有成熟的防范爬虫机制，会遇到 AI 无法阅读足够多文章的情况。可以使用 Undermind 等专业学术文章搜索 AI 来辅助搜索

### Vibe Coding

核心点：不要把任务一股脑交给 Agent，注意 Demo，边界设置，并发性之类的。这些展开讲篇幅太长了，初期用到的人比较少。大家可以来 CPU 周常，找一些大佬，让他们推荐一点学习路径。

## 第四部分：Agent 能力边界分析

### 上文提到过，用 Agent 浏览需要输入密码的网址，有泄露密码的风险

### 浏览网址时可能无法浏览全部信息，LLM 偷懒未总结全部信息，网站反爬虫制裁

这点前面已经说过了，这里强调一下

### 论文观点很难自主创新，可以作为探索 Idea 的辅助

AI 在厉害，输出的仍然是已有的数据，毕竟是靠文本训练与概率立身的。所以，你想要纯靠 AI 搞出来一个超厉害的创新点，很难。可以装一个 Skill：ARS-Codex。和她讨论你的 Idea，她会像亚里士多德一样对你的 Idea 进行深入质疑，直到你的 Idea 变得非常美味。有关这方面可以上网深入了解

### 电脑故障排查与 LLM 智力强关联

能力差的模型和 Agent 可以让你在这个过程非常的煎熬

### Agent 在写作方面文采很糟糕，制作的 PPT、PDF、文章一样就能看出是不是 AI，看多了之后还可以看出是哪个 Agent，东西能看但看多了很恶心，所以，想要创作一下美好事物还是人脑优先吧

怎么把 AI 文变得美味在前面已经说过了。这里强调一下，希望大家少用 AI 产出一下难以阅读的垃圾文章，现在每天和 AI 的沟通已经够多了，实在不想一打开推文又是 AI 执笔的文章，实在是读麻了。这篇文章读下来应该可以发现是我手搓的，在大 AI 时代下，有没有感受到我的诚意了吗？

## 第五部分：AI Agent 使用中的一些坑

1. 长期工作建议在项目中进行，并建立共享文件夹，方便开新对话。对话上下文有限制，太长了 AI 会降智，可以考虑装个 Skill。
2. 不同类型任务分不同窗口回答，保证上下文纯净度。
3. 注意及时让 AI 总结已有对话内容，防止过长上下文限制实力，并提高缓存命中率以节省费用。用 DSH 的朋友可能比较熟悉。
4. 注意 AI 在学术工作中的边界，不能代写，别人的工作成果可能会被 LLM 训练，小心你的文章中出现别人的产出（citation）。
5. LLM 的能力虽然很前无古人后无来者，但是它只会输出已有内容，不要被它的内容打压自己的创造力。
6. 多依靠自己的阅读能力，警惕过度依赖 AI 辅助文本阅读。
